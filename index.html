iOS 免费去广告

视频里那套叫 Jinx：试用 14 天，之后 3 元/月 或 24 元买断。
这里是免费替代，四条路，按愿意折腾的程度挑一条。

零成本不用装 App1 分钟

原理：iOS 去广告 App 的本质就是「把广告域名解析成 0.0.0.0」——广告 SDK 拿不到服务器地址， 开屏和插屏就加载失败。我们直接把 DNS 换成带广告过滤的解析器，效果一样，钱一分不花。

1Wi-Fi 改 DNS（最快，现在就能做）

不用装任何东西，30 秒：

  1. 设置 → 无线局域网 → 点当前 Wi-Fi 右边的 ⓘ
  2. 下滑到 配置 DNS → 改成 手动
  3. 删掉原有服务器，点「添加服务器」，填：
    94.140.14.14
    再加一条备用：94.140.15.15
  4. 点右上角 存储，然后开关一次 Wi-Fi
装完点这里自检拦截是否生效

局限：只对 Wi-Fi 生效，用蜂窝流量时不管用（iOS 不让改蜂窝 DNS，除非装 VPN 类 App）。

2App 方案（家庭 Wi-Fi + 蜂窝都管）

用免费开源的 Karing（App Store 免费，需美区 Apple ID）或 sing-box，导入我配好的规则：全部流量直连、只丢广告域名、可自己加域名、有拦截日志。

Karing / Clash / Stashclash.yaml
sing-box / SFI / Hiddifysing-box.json
AdGuard Home / 路由器hosts.txt
纯域名清单domains.txt

App 里「配置 → 添加 → 从链接导入」，粘贴上表对应文件的完整地址。这等价于 Jinx 的「DNS 保护」，但不装证书、不做中间人。

3全系统加密过滤（要自己有台服务器）

iOS 原生描述文件只支持加密 DNS（DoT/DoH），而境外 DoH 在国内 443 端口全被掐（本项目实测：AdGuard / Cloudflare / Google / Quad9 / ControlD 全部超时）。 所以这条路要你自己部署一个过滤解析器——doh/ 里有 Cloudflare Workers 和阿里云函数计算两版现成代码，免费额度足够个人用。

  1. 部署 doh/worker.js 或 doh/app.py，拿到自己的地址
  2. 跑 python make_profile.py --doh https://你的域名/dns-query
  3. 用 Safari 打开 dist/clean-dns-doh.mobileconfig 安装

提示：Cloudflare 的 *.workers.dev 在大陆基本不通，必须绑自己的域名。这里不提供现成的描述文件下载——那必须是你自己的地址，给假的等于骗你。

4只拦 Safari（最省事）

App Store 搜 AdGuard，免费版即可，在 Safari 设置里开启它的内容拦截器。网页广告基本清净，App 内广告它管不了（那是付费功能）。

能拦住什么，拦不住什么

✅ 网页广告Safari、App 内置浏览器
✅ App 开屏/插屏只要它走域名请求广告接口（多数中小 App）
✅ 追踪/统计双击、Google Ads、AppLovin、Unity 等
⚠️ 国内大厂广告抖音、淘宝、微博用 IP 直连 / 私有 HTTPDNS，DNS 层拦不到。Jinx 靠装根证书做中间人破解，代价是把全部 HTTPS 流量交给它
❌ 已缓存广告改完先清后台再重启手机，效果才明显（UP 主也这么说）
