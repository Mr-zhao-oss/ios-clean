iOS 免费去广告

视频里那套叫 Jinx，试用 14 天后 3 元/月。
这里是它的免费替代：不装 App、不装证书、不越狱。

零成本系统级1 分钟

原理：iOS 去广告 App 的本质是「接管 DNS」——广告 SDK 请求广告域名时，DNS 直接回 0.0.0.0，广告请求发不出去，开屏/插屏就加载失败。
我们把系统 DNS 指向带广告过滤的解析器，效果一样，钱一分不花。

① 下载描述文件 ② 装完点这里自检拦截是否生效

安装步骤

  1. 用 Safari 打开本页（微信里点开不行，右上角选「在 Safari 中打开」）
  2. 点上面的「下载描述文件」→ 弹窗选允许
  3. 打开 设置 → 顶部「已下载的描述文件」→ 选择它 → 安装 → 输锁屏密码
  4. 装完回到浏览器，点「自检」确认广告域名已被拦

删掉它：设置 → 通用 → VPN 与设备管理 → 删除「免费去广告·DNS 过滤」。系统 DNS 立刻恢复原样。

能拦住什么，拦不住什么

✅ 网页广告Safari、App 内置浏览器
✅ App 开屏/插屏只要它走域名请求广告接口（多数中小 App）
✅ 追踪/统计双击、Google 广告、AppLovin、Unity 等
⚠️ 国内大厂广告抖音、淘宝、微博等用 IP 直连 / 私有 HTTPDNS，DNS 层拦不到——Jinx 靠装证书中间人破解，代价是把你所有 HTTPS 流量交给第三方
❌ 已缓存的广告装完先清一遍后台再重启手机，效果才明显（UP 主也是这么说的）

想要更彻底：用规则表自己拦

DNS 描述文件用的是公共过滤列表，国内广告域名覆盖不全。下面这套是我整理的规则文件，装在免费开源的 Karing / sing-box 里，本地拦截、可自己加域名、还能看拦截日志：

Karing / Clashclash.yaml
sing-boxsing-box.json
AdGuard Home / 路由器hosts.txt
纯域名清单domains.txt

App 里「配置 → 添加 → 从链接导入」，粘贴本页对应文件的地址即可。全部流量直连，只是把广告域名丢弃，不需要任何机场或节点。

隐私说明

描述文件方案会把你的域名查询发给 AdGuard 的公共 DNS（94.140.14.14，官方声明不记录个人日志）。明文 DNS 理论上可被运营商看到。如果你介意，doh/ 目录里有一份自建加密 DoH 的代码，配 python make_profile.py --doh 你的地址 就能生成纯 DoH 版描述文件，查询全程加密、规则归你。
